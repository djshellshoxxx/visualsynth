# User Guide

VisualSynth is not a released product yet. The app is served from the Vite dev server:

```bash
npm install
npm run serve     # open http://127.0.0.1:4173
```

The live site is planned at `https://djshellshoxxx.github.io/visualsynth/`; it is not confirmed by this page.

What the specs say the instrument will do (planned, not all implemented): modular patching with visible
cables, a starter patch, MIDI and computer-keyboard input, scopes and spectrum views, patch save/load in a
versioned JSON format, and an educational mode that can be switched off. Check `spec/REQUIREMENTS_MATRIX.md`
for what is verified.
